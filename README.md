# Visfits: Wreckshift

[Play the game](https://lvdq132.github.io/visfits-wreckshift/)

A miniature precision-demolition game for browser and Meta Quest. Clear coral towers while keeping mint landmarks standing. Built with Meta IWSDK and Havok physics.

This repository holds the compiled playable release. Dependency notices ship in THIRD-PARTY-NOTICES.txt. Source maps, private entry details, account credentials, and local test artifacts are not deployment inputs.

Release updates are explicit commits. Do not change the submitted build or materials after the competition deadline, November 18, 2026 at 20:00 UTC, until judging is complete.
